概述

条件转移指令根据标志寄存器（EFLAGS/RFLAGS）中的标志位状态决定是否跳转，是实现分支逻辑（if/else、循环、switch）的核心指令。比较类指令通常紧跟 CMP 之后——CMP 执行减法但不保存结果，只更新标志位，随后条件转移指令读取标志位决定走向，广泛应用于程序逻辑控制。

测试 CX/ECX 寄存器条件转移指令

指令助记符判断条件说明作用
JCXZCX = 0CX 寄存器内容为 0 时转移
JECXZECX = 0ECX 寄存器内容为 0 时转移（适用于 32 位处理器）

有符号数比较条件转移指令

用于比较两个有符号数的大小，通常紧跟 CMP 指令之后。

指令助记符判断条件说明作用
JG / JNLEZF=0 且 SF=OF大于（A > B）时转移
JGE / JNLSF = OF大于等于（A ≥ B）时转移
JL / JNGESF ≠ OF小于（A < B）时转移
JLE / JNGZF=1 或 SF ≠ OF小于等于（A ≤ B）时转移

有符号比较同时依赖符号位（SF）与溢出标志（OF）：发生溢出时 SF 与真实符号相反，因此用 SF=OF / SF≠OF 组合判断真实大小关系。

无符号数比较条件转移指令

用于比较两个无符号数的大小，通常紧跟 CMP 指令之后。

指令助记符判断条件说明作用
JA / JNBECF=0 且 ZF=0高于（A > B）时转移
JAE / JNBCF = 0高于等于（A ≥ B）时转移
JB / JNAECF = 1低于（A < B）时转移
JBE / JNACF=1 或 ZF=1低于等于（A ≤ B）时转移

无符号比较只依赖进位标志（CF）与零标志（ZF）：CMP 做减法时若产生借位则 CF=1，表示被减数更小。

单标志位条件转移指令

指令助记符判断条件说明作用
JCCF = 1有进位/借位时转移
JNCCF = 0无进位/借位时转移
JZ / JEZF = 1结果为零/相等时转移
JNZ / JNEZF = 0结果非零/不相等时转移
JSSF = 1结果为负时转移
JNSSF = 0结果为正时转移
JP / JPEPF = 1结果中 1 的个数为偶数时转移
JNP / JPOPF = 0结果中 1 的个数为奇数时转移
JOOF = 1有溢出时转移
JNOOF = 0无溢出时转移

总结

  • 无条件 vs 条件：所有条件转移指令均需配合 CMP（或其他更新标志位的算术指令）使用，根据标志位状态决定是否跳转；否则标志位是上一条运算留下的、与比较无关的结果。
  • 有符号看 SF/OF，无符号看 CF/ZF：同一个 CMP 结果，有符号比较用 JG/JL 系列，无符号比较用 JA/JB 系列，混用会导致分支判断错误——逆向分析时首先要确定比较的操作数是有符号还是无符号。
  • 别名成对：多数指令有等价别名（JE=JZ、JAE=JNB、JGE=JNL），反汇编器输出的助记符可能不同但语义一致。
  • 逆向识别：cmp/test 紧跟 jcc 是 if 语句的典型模式；loop 系列与 JECXZ 常对应循环结构的计数判断。
