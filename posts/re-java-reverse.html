常用工具：JEB、Jadx 和 Die。

JEB / Jadx 具体怎么好用，目前谁也说不准谁最好，有的人觉得 JEB 好用些，有的人觉得 Jadx 也好用。注意：弄这两个必须熟悉 Java 语言。

Die 是目前我见过的，识别最准的查壳信息工具。
