定义

利用 #define 来定义常量，或者使用 const 将变量定义为常量。#define 定义常量名称，编译器在编译时，会将代码之中的宏名称直接替换对应的信息。Const 是为了增加程序的健壮性存在的，常用于 strcpy 的第二个参数定义为一个常量，防止参数被修改，对源字符串造成破坏。

代码
#include <stdio.h>

#define NUMBER_ONE 1

int main(int argc, char* argv[]){
    const int n = NUMBER_ONE;
    printf("const = %d\n#define = %d \r\n", n, NUMBER_ONE);
    return 0;
}

此处添加 /P 编译选项会生成预处理文件。

define 与 const 对比

#define 定义的宏在预处理阶段完成替换，不占用运行时间，但它不进行类型检查。const 定义的常量在编译阶段处理，具有类型检查，更安全。

修改 const 变量

const 变量虽然不能直接修改，但可以通过指针间接修改它的值。以下代码演示了这一行为：

#include <stdio.h>

int main(int argc, char* argv[]){
    const int n1 = 5;
    int *p = (int*)&n1;
    *p = 6;
    int n2 = n1;
    return 0;
}
原因

const 只是告诉编译器该变量是只读的，但在内存层面它仍然是一个普通的变量，存储在栈上。通过指针强制去除 const 限定后，就可以修改它指向的内存。

注意：三个平台下，虽然通过指针修改了 n1 所在内存的值为 6，但 n2 = n1 仍然得到 5。这是因为编译器将 const 变量的值进行了常量传播优化，直接将 n1 替换为字面量 5。这证明了 const 的"只读"是通过编译器约束实现的，而非内存保护。
