概述

除法已经讲完了，来说一下取模。编译器在生成取模运算的汇编代码时，会根据除数是否为 2 的幂采取完全不同的优化策略：2 的幂被转换为位掩码（and）配合符号修正，而非 2 的幂则先用魔数乘法求出商，再用被除数减去「商 × 除数」得到余数。本文通过同一份代码在 MinGW 与 MSVC（64→64 / 64→32）下的三组汇编输出，分析取模运算的指令特征。

汇编实例

示例代码分别对 8（2的幂）和 9（非2的幂）取模：

printf("argc %% 8 = %d", argc % 8);
printf("argc %% 9 = %d", argc % 9);
MinGW 汇编
main(int, char**):
    push   %rbp
    mov    %rsp,%rbp
    sub    $0x20,%rsp
    mov    %ecx,0x10(%rbp)
    mov    %rdx,0x18(%rbp)
    call   0x7ff7410d1837              ; <__main>
    mov    0x10(%rbp),%eax             ; eax = argc
    cltd
    shr    $0x1d,%edx                  ; edx >> 29（这里相当于判断符号）
    add    %edx,%eax                   ; eax = argc + (argc < 0 ? 7 : 0)
    and    $0x7,%eax                   ; eax = eax & 7
    sub    %edx,%eax                   ; 减回修正量
    mov    %eax,%edx
    lea    0x88f5(%rip),%rax           ; 0x7ff7410da000
    mov    %rax,%rcx
    call   0x7ff7410d8e40              ; <printf(char const*, ...)>
    mov    0x10(%rbp),%edx             ; edx = argc
    movslq %edx,%rax
    imul   $0x38e38e39,%rax,%rax       ; rax = argc * 0x38e38e39
    shr    $0x20,%rax                  ; rax = rax >> 32（逻辑右移）
    sar    %eax                        ; eax = eax >> 1（算术右移）
    mov    %edx,%ecx                   ; ecx = argc
    sar    $0x1f,%ecx                  ; ecx = argc >> 31（取符号位）
    sub    %ecx,%eax                   ; eax = argc / 9
    mov    %eax,%ecx                   ; ecx = eax
    shl    $0x3,%ecx                   ; ecx = eax << 3
    add    %eax,%ecx                   ; ecx = (eax << 3) + eax = 9*q
    mov    %edx,%eax
    sub    %ecx,%eax                   ; eax = argc - 9 * (argc / 9)
    mov    %eax,%edx
    lea    0x88bf(%rip),%rax           ; 0x7ff7410da000
    mov    %rax,%rcx
    call   0x7ff7410d8e40              ; <printf(char const*, ...)>
    mov    $0x0,%eax
    add    $0x20,%rsp
    pop    %rbp
    ret

分析：第一段（% 8）中，shr $0x1d 把符号位右移到最低位，负数时得到 7、正数时得到 0，作为偏移量加入后再 and $0x7 取低 3 位，最后减回偏移量 —— 这就是 2 的幂取模的符号修正过程。第二段（% 9）先用魔数 0x38e38e39 配合移位求出 argc / 9，再通过 argc - 9*q 得到余数，属于典型的「先求商再回乘相减」。

MSVC 汇编（64→64）
64->64
main(int,char **):
    movq   %rdx, 0x10(%rsp)
    movl   %ecx, 0x8(%rsp)
    pushq  %rdi
    subq   $0x20, %rsp
    movl   0x30(%rsp), %eax            ; eax = argc
    cltd                                ; 扩展 eax
    andl   $0x7, %edx                  ; edx = edx & 7（负数得 7，正数得 0）
    addl   %edx, %eax                  ; eax = eax + edx
    andl   $0x7, %eax                  ; eax = eax & 7
    subl   %edx, %eax                  ; (argc + (argc<0?7:0)) & 7 - (argc<0?7:0)
    movl   %eax, %edx
    leaq   0x86ca(%rip), %rcx
    callq  0x140001195                 ; printf
    movl   0x30(%rsp), %eax            ; eax = argc
    cltd                                ; 扩展
    movl   $0x9, %ecx
    idivl  %ecx                        ; eax = argc / 9, edx = argc % 9
    movl   %edx, %eax
    movl   %eax, %edx
    leaq   0x86b6(%rip), %rcx
    callq  0x140001195                 ; printf
    xorl   %eax, %eax
    addq   $0x20, %rsp
    popq   %rdi
    retq

分析：2 的幂取模与 MinGW 思路一致，cltd 符号扩展后 and $0x7 得到修正量（负数 7、正数 0），加偏移 → and 取低位 → 减回偏移。非 2 的幂（% 9）则直接使用 idiv 硬件除法指令，余数保存在 edx 中。

MSVC 汇编（64→32）
64->32
main(int,char **):
    pushl  %ebp
    movl   %esp, %ebp
    movl   0x8(%ebp), %eax
    andl   $0x80000007, %eax           ; imm = 0x80000007
    jns    0x4014d2                     ; eax 符号位为 0（argc >= 0）时跳转
    decl   %eax
    orl    $-0x8, %eax
    incl   %eax                         ; 负数取模修正
    pushl  %eax
    pushl  $0x606b30                    ; imm = 0x606B30
    calll  0x40119a                     ; _printf
    addl   $0x8, %esp
    movl   0x8(%ebp), %eax              ; eax = argc
    cltd                                ; 扩展（后面是正常的除法操作）
    movl   $0x9, %ecx
    idivl  %ecx
    pushl  %edx
    pushl  $0x606b38                    ; imm = 0x606B38
    calll  0x40119a                     ; _printf
    addl   $0x8, %esp
    xorl   %eax, %eax
    cmpl   %esp, %ebp
    calll  0x4010ff                     ; __RTC_CheckEsp
    popl   %ebp
    retl

分析：andl $0x80000007 一条指令同时完成符号位保留与低 3 位提取（0x80000007 = 符号位 | 7 的掩码），随后用 jns 判定：正数直接使用结果，负数走 decl → orl → incl 修正。非 2 的幂同样使用 idiv。

2的幂取模四种方案

方案1：位掩码 + 符号判定

对 2k 取余，余数只需要被除数低 k 位的值；如果是负数，需要在第 k 位之前补 1（保留符号位）。代码模板：

mov  reg, 被除数
and  reg, 80000007h        ; 掩码 = 符号位 | (2^k - 1)
jns  lab1                  ; 符号位为 0（非负）直接跳过
or   reg, 0FFFFFFF8h       ; 负数：高位补 1
lab1:

余数的值非 0 时没有问题；如果结果恰好为 0 则可能是错误的（负数被修正成了错误值）。调整方法是在 or 运算之前先 -1，or 算完之后再 +1。如果余数不为 0，不影响计算结果。模板：

mov  reg, 被除数
and  reg, 80000007h        ; 掩码由 2^k 决定
jns  lab1
dec  reg
or   reg, 0FFFFFFF8h
inc  reg
lab1:

碰到这个就能判定是取模代码，原型是变量对 2k 执行取模运算。还原方法：直接去掉高位、保留低位，统计低位有多少个 1 就能得到 k 值。

方案2：正负数分别处理

对 2k 取余，正数使用方案1，负数可以使用下面的调整公式：

x % 2^k = (x + 2^(k-1)) & (2^k - 1) - 2^(k-1)

遇到这个公式也可以判定是取模代码，原型是变量对 2k 执行取模运算。还原方法：直接看 and reg, 0FFFFFFF8h，统计低位一共保留了多少个 0 即可得到 k 的值。

方案3：高位清除修正

对 2k 取余，正数使用以下调整公式：

x % 2^k = x - (x & ~(2^k - 1))

对负数使用以下调整公式：

x % 2^k = x - ((x + 2^(k-1)) & ~(2^k - 1))

遇到这个公式也可以判定是取模代码，原型是变量对 2k 执行取模运算。还原方法：直接看 and reg, 0FFFFFFF8h，统计低位一共保留了多少个 0 即可得到 k 的值。

方案4：非2的幂

对非 2k 取余，根据取模定义：

r = a % b

根据性质可以得到：

r = a - q * b = a - (a / b) * b

碰到这个很简单，直接看除数 b 就可以了。通常的表现形式是：魔数乘法（或 idiv）求商，随后 被除数 - 商 * 除数 得到余数。

总结

  • 除数为 2 的幂：识别特征是 and 位掩码（如 0x80000007、0FFFFFFF8h）配合 jns/cltd 符号判定与加减修正。还原时统计掩码低位的 1（或保留的 0）的个数得到 k，即原始运算为 x % 2^k。
  • 除数非 2 的幂：识别特征是先通过魔数乘法 + 移位或 idiv 求商，再执行 被除数 - 商 * 除数。还原时直接读取回乘的常数即为除数。
  • MinGW vs MSVC：MinGW 偏好魔数乘法 + 移位求商的纯指令序列；MSVC 在非 2 的幂场景常直接使用 idiv，在 64→32 场景下则常用单条 and 0x80000007 + jns 分支完成 2 的幂取模。
