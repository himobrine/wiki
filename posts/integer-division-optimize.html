概述

在 x86 汇编中，除法指令分为有符号 idiv 和无符号 div。两个无符号数相除结果仍为无符号；两个有符号数相除结果仍为有符号。若混合使用，有符号数的最高位（符号位）会被当作数据位处理。

编译器在开启优化时，会将常量除法替换为更高效的乘法+移位指令组合。本文将系统讲解各种情况下的优化策略。

取整方式

C 语言默认采用向0取整：+3.5 取整为 3，-3.5 取整为 -3。其他取整方式包括：

  • 向下取整 (floor)：使用 math.h 的 floor 函数。当除数为2的幂时可用带符号右移 (sar) 完成，但负数结果与 C 语言默认行为不同。
  • 向上取整 (ceil)：使用 math.h 的 ceil 函数。同样存在问题。

无符号2的幂优化

当除数为无符号2的幂时，编译器直接使用无符号右移 shr 替代除法。

代码示例
#include <stdio.h>

int main(int argc, char* argv[]){
    printf("argc / 16 = %u", (unsigned)argc / 16);
    return 0;
}
MinGW 汇编（开启 O2）
main(int, char**):
    push   %rbx
    sub    $0x20,%rsp
    mov    %ecx,%ebx              ; ebx = argc
    call   <__main>
    shr    $0x4,%ebx              ; ebx = ebx >> 4 (即 argc / 16)
    lea    0x11da(%rip),%rcx      ; 0x7ff6452fa000
    mov    %ebx,%edx
    call   <printf>
    xor    %eax,%eax
    add    $0x20,%rsp
    pop    %rbx
    ret
MSVC 汇编（开启 O2）
main(int,char **):
    subq   $0x28, %rsp
    shrl   $0x4, %ecx             ; ecx = argc / 16
    movl   %ecx, %edx
    leaq   0x6750(%rip), %rcx     ; `string'
    callq  printf
    xorl   %eax, %eax
    addq   $0x28, %rsp
    retq

结论：开启优化时，2的幂除法被替换为无符号右移 shr。

无符号非2的幂

类型1：乘法+移位（除以3）
printf("argc / 3 = %u", (unsigned)argc / 3);

MinGW 汇编（开启 O2）：

    mov    %ebx,%edx
    mov    $0xaaaaaaab,%eax       ; 魔数 0xAAAAAAAB
    imul   %rax,%rdx              ; rdx = argc * 0xAAAAAAAB
    shr    $0x21,%rdx             ; rdx >> 33

MSVC 汇编（开启 O2）：

    movl   $0xaaaaaaab, %eax      ; eax = 0xAAAAAAAB
    mull   %ebx                   ; eax = argc * 0xAAAAAAAB
    shrl   %edx                   ; edx = 高32位 >> 1

结论：使用 mul/imul 无符号乘法 + 移位时，基本可判定为除法优化。公式为：

x / c ≈ (M * x) >> n

其中 M 为魔数，n 为总右移次数。可通过 c ≈ 2^n / M 反推原始除数。

类型2：乘法+加减调整（除以7）
printf("argc / 7 = %u", (unsigned)argc / 7);

MSVC 汇编（开启 O2，64→32）：

    movl   $0x24924925, %eax      ; 魔数 0x24924925
    mull   %esi                   ; edx:eax = argc * 0x24924925
    subl   %edx, %esi             ; esi = esi - edx
    shrl   %esi                   ; esi >> 1
    addl   %edx, %esi             ; esi = esi + edx
    shrl   $0x2, %esi             ; esi >> 2（一共 >> 35）

MinGW 汇编（开启 O2）：

    imul   $0x24924925,%rsi,%rsi  ; 魔数 0x24924925
    shr    $0x20,%rsi             ; rsi >> 32
    sub    %esi,%ebx              ; ebx = ebx - esi
    shr    %edx                   ; >> 1
    add    %esi,%edx              ; edx = edx + esi
    shr    $0x2,%edx              ; >> 2

结论：这种情况下公式变为 x / c = ((x * M) >> n) + x 类的调整形式。统计右移总次数确定 n 值，使用 c = 2^n / M 求解。

有符号2的幂优化（除以8）

printf("argc / 8 = %u", argc / 8);

关键汇编（关闭 O2，MSVC）：

    movl   0x8(%ebp), %eax        ; eax = argc
    cltd                          ; 符号扩展 (eax -> edx:eax)
    andl   $0x7, %edx             ; edx = edx & 7
    addl   %edx, %eax             ; eax = eax + edx
    sarl   $0x3, %eax             ; eax >> 3

关键汇编（开启 O2，MinGW）：

    test   %ebx,%ebx              ; 测试 argc 符号
    lea    0x7(%rbx),%edx         ; edx = argc + 7
    cmovs  %ebx,%edx              ; 条件执行: 若负数则 edx = argc
    sar    $0x3,%edx              ; 若负数 eax = argc >> 3
                                  ; 若正数 eax = (argc + 7) >> 3

关键汇编（开启 O2，MSVC）：

    cltd                          ; 符号扩展
    andl   $0x7, %edx             ; edx = (argc < 0)? 7 : 0
    addl   %eax, %edx             ; edx = argc + eax
    sarl   $0x3, %edx             ; edx >> 3

结论：对有符号数做 sar（算术右移）相当于向下取整，而 C 语言要求向0取整，因此编译器会加入偏移调整（如 argc + 7 再右移）来修正。根据 n（右移次数）即可恢复除法原型。

有符号非2的幂

类型1：乘法+移位（除以9）
printf("argc / 9 = %u", argc / 9);

MinGW 汇编（开启 O2）：

    movslq %ebx,%rdx              ; 符号扩展到64位
    sar    $0x1f,%ebx             ; ebx >> 31 (取符号位)
    imul   $0x38e38e39,%rdx,%rdx  ; rdx = argc * 魔数
    sar    $0x21,%rdx             ; rdx >> 33
    sub    %ebx,%edx              ; ebx = edx - 符号位

MSVC 汇编（开启 O2）：

    movl   $0x38e38e39, %eax      ; 魔数 0x38E38E39
    imull  %esi                   ; eax = argc * 魔数
    sarl   %edx                   ; edx >> 1
    movl   %edx, %eax
    shrl   $0x1f, %eax            ; eax >> 31 (取符号位)
    addl   %edx, %eax             ; eax = eax + edx

结论：imul 表明是有符号计算。操作数为被除数，魔数 0x38E38E39，统计右移总次数确定 n 值，使用公式求解除数。公式为：

若 n 为偶数则 x / c ≈ (x * M) >> n，若 n 为奇数则 x / c ≈ ((x * M) >> n) - sign(x)

类型2：乘法+加减调整（除以7）
printf("argc / 7 = %u", argc / 7);

MSVC 汇编（开启 O2，64→32）：

    movl   $0x92492493, %eax      ; 魔数 0x92492493
    imull  %ebx                   ; eax = argc * M
    addl   %ebx, %edx             ; edx = (argc * M) + argc
    sarl   $0x2, %edx             ; edx >> 2
    movl   %edx, %eax
    shrl   $0x1f, %eax            ; eax >> 31
    addl   %eax, %edx             ; edx = edx + eax（恢复标志位，向上取整）

MinGW 汇编（关闭 O2）：

    imul   $0xffffffff92492493,%rdx,%rdx ; 魔数 (补码形式)
    shr    $0x20,%rdx             ; rdx >> 32
    add    %eax,%edx              ; edx = edx + argc
    sar    $0x2,%edx              ; edx >> 2
    sar    $0x1f,%eax             ; 取符号位
    mov    %eax,%ecx
    mov    %edx,%eax
    sub    %ecx,%eax              ; eax = eax - 符号位

结论：imul 表明有符号计算，魔数 0x92492493，公式类似上述，通过统计 n 值恢复除法原型。

有符号负除数

负2的幂（除以-4）
printf("argc / -4 = %u", argc / -4);

MinGW 汇编（开启 O2）：

    test   %ebx,%ebx              ; argc的符号
    lea    0x3(%rbx),%edx         ; edx = argc + 3
    cmovns %ebx,%edx              ; if(argc >= 0) edx = argc; 否则 edx = argc + 3
    sar    $0x2,%edx              ; edx >> 2
    neg    %edx                   ; edx = -edx (取反)

MSVC 汇编（开启 O2）：

    cltd                          ; 符号扩展
    andl   $0x3, %edx             ; edx = (argc < 0)? 3 : 0
    addl   %eax, %edx             ; edx = argc + edx
    sarl   $0x2, %edx             ; edx >> 2
    negl   %edx                   ; edx = -edx

结论：与正2的幂类似，但最后加 neg 指令取反。根据 n 值恢复除法原型。

负非2的幂（除以-5）
printf("argc / -5 = %u", argc / -5);

MSVC 汇编（开启 O2）：

    movl   $0x99999999, %eax      ; 魔数 0x99999999
    imull  %esi                   ; eax = argc * M
    sarl   %edx                   ; edx >> 1
    movl   %edx, %eax
    shrl   $0x1f, %eax            ; eax >> 32
    addl   %edx, %eax             ; eax = edx + eax

MinGW 汇编（开启 O2）：

    imul   $0x66666667,%rsi,%rsi
    sar    $0x21,%rsi             ; rsi >> 33
    sar    $0x2,%edx              ; edx >> 2
    neg    %edx                   ; 取反

结论：魔数 0x99999999 / 0x66666667，由于魔数大于 7FFFFFFFh，且 imul 和 sar 之间未见调整代码，故认定除数为负，魔数以补码形式参与计算。

总结

无符号除法 (mul)
  • 类型1: x / c = (x * M) >> n — 统计 n，用 c = 2^n / M 求解
  • 类型2: x / c = ((x * M) >> n) + x 形式的调整 — 统计 n，用 c = 2^n / M 求解
有符号正除数 (imul)
  • 类型1: x / c = (x * M) >> n - sign(x) — n为总右移次数
  • 类型2: x / c = ((x * M) >> n) + x - sign(x) — 含加减调整
有符号负除数 (imul + neg/sub)
  • 魔数 > 7FFFFFFFh：魔数以补码形式直接参与，无需调整
  • 魔数 <= 7FFFFFFFh：imul 和 sar 之间有 sub 指令调整
识别方法
  1. mul (无符号乘法) -> 无符号除法优化
  2. imul (有符号乘法) -> 有符号除法优化
  3. 观察魔数大小判断除数正负
  4. 统计所有 shr/sar 的右移总次数得到 n
  5. 用公式 c = 2^n / M 求解原始除数的近似值，四舍五入取整即可恢复
