概述

在 x86 汇编中，乘法指令有 imul（有符号）和 mul（无符号）。编译器会尝试把乘法转换为加法或左移（当乘数是 2 的幂），否则使用乘法指令。

代码

#include <stdio.h>

int main(int argc, char* argv[]){
    int n1 = argc;
    int n2 = argc;

    printf("n1 * 15 = %d\r\n", n1 * 15);
    printf("n1 * 16 = %d\r\n", n1 * 16);
    printf("2 * 2 = %d\r\n", 2 * 2);
    printf("n2 * 4 + 5 = %d\r\n", n2 * 4 + 5);
    printf("n1 * n2 = %d\r\n", n1 * n2);
    return 0;
}

总结

  • 当乘数是 2 的幂时，编译器会采用左移指令（shl）替代乘法。
  • 非 2 的幂但能用常量折叠的情况（如 n1*15），会先左移后减去原数实现 n*16 - n。
  • 有符号乘法指令 imul 用于变量间乘法（n1*n2），因为无法通过移位/加法进一步简化。
  • MSVC 调试构建会在栈上填充 0xCCCCCCCC 并插入 RTC 检查，以帮助捕获未初始化变量和栈溢出。
