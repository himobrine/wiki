Impossible 难度

代码分析
<?php
/*

Only the admin user is allowed to access this page

*/

if (dvwaCurrentUser() != "admin") {
    print "Unauthorised";
    http_response_code(403);
    exit;
}
?>

也是和前面的代码一样。所有功能在允许访问数据之前都能正确检查授权。但是，页面上可能存在一些与授权无关的问题，因此请勿将其注销为完全安全。
