题目描述

密文使用的是 aes-cbc 加密，密钥通过 ECDH 密钥交换协议协商：S = aB = abG，取 x 坐标作为共享密钥。

已知 p（大素数）、G（基点 x 坐标）、A（公钥 x 坐标）、B（公钥 x 坐标），以及 iv 和密文 ct。需要利用 MOV 攻击求解共享秘密，从而解密 flag。

思路分析

MOV（Menezes–Okamoto–Vanstone）攻击的核心思想：利用 Tate Pairing（或 Weil Pairing）将椭圆曲线上的离散对数问题（ECDLP）归约到有限域扩展域上的离散对数问题（DLP）。由于本题椭圆曲线为 y² = x³ + x（a = 1, b = 0），属于超奇异椭圆曲线，存在有效的 distortion map，使得 MOV 攻击可行。

攻击流程：

  1. 将曲线提升到二次扩域 GF(p²)
  2. 使用 distortion map 将基点 G 映射到扩域上的点 φ(G)
  3. 计算 Tate pairing e(G, φ(G)) 作为 DLP 的底
  4. 计算 Tate pairing e(A, φ(G)) 作为 DLP 的目标
  5. 在扩域上求解 DLP 得到私钥 a
  6. 计算共享秘密 S = aB，取 x 坐标派生 AES 密钥
  7. AES-CBC 解密得到 flag

SageMath 攻击脚本

#!/usr/bin/env sage-python

from sage.all import *
from hashlib import sha256
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad

# Given data
p = 11758811435299197782325894202410990650649601282525961620527876664622930378615087
Gx = 246940630984360367198777777917942309731789700393587038646467058370636374388694
Ax = 1227149150917613863955629279240024528868616016808343910406685156976840720601489
Bx = 8827065846723574379455440495801260174628053954669240449781141038653567984952299
iv_hex = "b7e803357c74bd4e630e1b09e0701b40"
ct_hex = "17b7bd4b6a070c732db1d692a5544cec646139199102552824910cd1bd5a7d7927624d903ca4cc686369b0dcfb96e00bfe01468841b16d38183b49da69f833b9"

# Convert hex to bytes
iv = bytes.fromhex(iv_hex)
ct = bytes.fromhex(ct_hex)

print(f"p = {p}")
print(f"Gx = {Gx}")
print(f"Ax = {Ax}")
print(f"Bx = {Bx}")

# Setup curve
F = GF(p)
E = EllipticCurve(F, [1, 0])

# Lift points
G = E.lift_x(F(Gx))
A = E.lift_x(F(Ax))
B = E.lift_x(F(Bx))

print(f"G = {G}")
print(f"A = {A}")
print(f"B = {B}")

FIELD_BYTES = (ZZ(p).nbits() + 7) // 8

def derive_key(P):
    x = int(P[0])
    key_material = x.to_bytes(FIELD_BYTES, "big")
    return sha256(key_material).digest()

def decrypt_flag(key, iv, ct):
    cipher = AES.new(key, AES.MODE_CBC, iv)
    pt = unpad(cipher.decrypt(ct), 16)
    return pt

# MOV Attack
print("\n" + "="*50)
print("Using MOV attack...")
print("="*50)

# Create quadratic extension
R = PolynomialRing(F, 'x')
x = R.gen()
F2 = GF(p**2, modulus=x**2 + 1, name='i')
i = F2.gen()

E2 = EllipticCurve(F2, [1, 0])

# Map points
G2 = E2(G)
A2 = E2(A)
B2 = E2(B)

# Distortion map
def distortion_map(P):
    x_coord, y_coord = P.xy()
    return E2(-x_coord, i*y_coord)

phi_G = distortion_map(G2)
phi_A = distortion_map(A2)

# Get order
n = G.order()
print(f"Group order: {n}")
print("Computing Tate pairings...")

pairing_base = G2.tate_pairing(phi_G, n, 2)
pairing_target = G2.tate_pairing(phi_A, n, 2)

print("Solving discrete log...")
a = discrete_log(pairing_target, pairing_base)
print(f"Found a = {a}")

# Verify
if a*G == A:
    print("Verification successful!")
    S = a * B
elif a*G == -A:
    print("Using negated A")
    A = -A
    S = a * B
else:
    print("Trying to find b instead...")
    phi_B = distortion_map(B2)
    pairing_target_b = G2.tate_pairing(phi_B, n, 2)
    b = discrete_log(pairing_target_b, pairing_base)
    print(f"Found b = {b}")
    S = b * A

print(f"Shared secret x: {S[0]}")

# Decrypt
key = derive_key(S)
print(f"Key: {key.hex()}")
flag = decrypt_flag(key, iv, ct)
print(f"\nFlag: {flag.decode()}")

运行结果

脚本通过 MOV 攻击成功计算出私钥 a，验证通过后计算共享秘密 S，派生 AES 密钥并解密出 flag。
