补码原理

减法对应的汇编指令是 sub。虽然计算机只做加法，但可以通过补码将减法转换为加法：

y + y（反） = 0 - y
⇔ y（反 + 1） = -y
⇔ y（补） = -y

代码

#include <stdio.h>

int main(int argc, char* argv[]){
    int n1 = argc;
    int n2 = 0;

    scanf("%d", &n2);
    n1 = n1 - 100;
    n1 = n1 + 5 - n2;

    printf("n1 = %d\r\n", n1);
    return 0;
}
