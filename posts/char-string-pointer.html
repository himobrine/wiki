字符与字符串

字符与字符串是 C/C++ 编程的基础。\0 作为字符串的终止标志。

字符的编码

编码格式主要分为两种：ASCII 和 Unicode。ASCII 只占 1 字节，值在 0-255 之间。

使用 char 存储 ASCII 格式的字符，使用 wchar_t 存储 Unicode 格式的字符。wchar_t 中兼容 ASCII 的字符高位为 0。

参考：ASCII 码一览表（非常详细） - C 语言中文网

字符串的存储方式

字符串的存储方式主要有两种：

  1. 定长方式

    优点：获取字符串长度不需要遍历。

    缺点：要存储字符串长度 n 的额外开销，且字符串不能超过长度范围。

  2. 终结符方式

    优点：没有长度限制，可存储任意长度的字符串。

    缺点：需要遍历计算长度，效率不高。

C/C++ 使用 \0 作为终止标志。ASCII 使用 1 字节的 \0，Unicode 使用 2 字节的 \0。注意：需要使用一个变量存储字符串的第一个字符位置，以便遍历操作。

逻辑判断中，0 和 0.0 为假，非 0 为真。

地址与指针的概念

C/C++ 中的地址用 16 进制表示。取一个变量的地址使用 & 运算符。只有变量才能取地址，没有地址的（如 const 常量、字面量）无法取地址。

指针使用 TYPE* 的形式定义，type 为指向的数据类型。任何数据都可以定义为指针，指针本身也是一种数据类型，也存储在内存中，也有自己的地址，因此可以有多级指针。

指针详解

不同指针指向同一地址

不同类型的指针指向同一地址时，读取的数据宽度不同。

#include <stdio.h>

int main(){
    int n = 0x12345678;
    int *p1 = &n;
    char *p2 = (char*)&n;
    short *p3 = (short*)&n;
    printf("%08x", *p1);
    printf("%08x", *p2);
    printf("%08x", *p3);
    return 0;
}

指针的偏移寻址方式
#include <stdio.h>

int main(int argc, char *argv[]){
    char ary[5] = {(char)0x01, (char)0x23, (char)0x45, (char)0x67, (char)0x89};
    int *p1 = (int*)ary;
    char *p2 = (char*)ary;
    short *p3 = (short*)ary;

    p1 += 1;
    p2 += 1;
    p3 += 1;
    return 0;
}

指针运算规则

指针保存的地址作为基址进行寻址，以 [基地址 + 偏移量] 的方式访问目标地址。地址寻址方式如下：

type *p; // type 为指向的数据类型
p + n : 目标地址 = 基地址 + sizeof(type) * n

注意：两个指针的值不可以相加（两个地址值相加得到的是一个新的地址，但该地址无法确定是否有意义，因此不允许相加）。

指针可以减法运算，乘法和除法没有意义（原因同上）。两个同类型指针（强转也可以）相减，得到的是指针指向的元素的个数。

type *p;
type *q;
p - q = ((int)p - (int)q) / sizeof(type)

引用

C++ 为简化操作，对指针操作进行了封装，提供了引用（Reference）类型。

引用的基本用法
#include <stdio.h>

void add(int &ref){
    ref++;
}

int main(int argc, char argv[]){
    int n = 0x12345678;
    int &ref = n;
    add(ref);
    return 0;
}

main(int, char*):
    push    %rbp
    mov     %rsp,%rbp
    sub     $0x30,%rsp
    mov     %ecx,0x10(%rbp)
    mov     %rdx,0x18(%rbp)
    call    __main
    movl    $0x12345678,-0xc(%rbp)   ; int n = 0x12345678
    lea     -0xc(%rbp),%rax
    mov     %rax,-0x8(%rbp)          ; int &ref = n (存地址)
    mov     -0x8(%rbp),%rax          ; 取n的地址
    mov     %rax,%rcx                ; 传递n的地址
    call    add(int&)                 ; 传地址
    mov     $0x0,%eax
    add     $0x30,%rsp
    pop     %rbp
    ret

引用本质

引用在底层实现上就是一个指针，编译器自动完成了取地址和解引用的操作，除此之外与指针没有太大区别。
