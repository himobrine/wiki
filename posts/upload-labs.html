关于 upload-labs

upload-labs 是一个使用 php 语言编写的，专门收集渗透测试过程中遇到的各种文件上传漏洞的靶场，用于学习文件上传漏洞攻击和防御。

项目地址：https://github.com/c0ny1/upload-labs

Docker 搭建

使用 Docker 可以快速完成部署：

docker pull c0ny1/upload-labs

拉取完成后启动容器：

docker run -d -p 80:80 c0ny1/upload-labs

启动后直接访问 http://127.0.0.1 即可进入靶场。

Windows 搭建

下载 upload-labs 源码（建议从 GitHub 下载 zip 包）：

https://github.com/c0ny1/upload-labs

将解压后的文件夹复制到 phpstudy 的 WWW 目录下。
无需数据库，直接访问 http://127.0.0.1/upload-labs 即可。
注意需要在靶场目录下手动创建一个 upload 文件夹用于存放上传的文件。
